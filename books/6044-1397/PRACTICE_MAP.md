# PRACTICE MAP — Standard 6044:1397 Interactive

## Purpose
این فایل قرارداد طراحی تمرین‌های v1.0 است. تمرین‌ها باید آموزشی باشند، اما هیچ عدد یا الزام جدیدی از خود پروژه نسازند.

هر تمرین شامل:
- **نوع**
- **هدف**
- **داده ورودی**
- **تصمیم مورد انتظار**
- **پاسخ/بازخورد**
- **مبنای منبع**
- **خطای رایج**
- **سطح**

اگر داده سناریو فرضی باشد، با برچسب «سناریوی آموزشی» مشخص می‌شود.

## Feedback contract

بازخورد پاسخ درست:
1. نتیجه درست را نشان بده.
2. یک دلیل کوتاه و روشن بده.
3. بند/جدول/پیوست منبع را نشان بده.
4. اگر عدد دارد، واحد را نشان بده.

بازخورد پاسخ غلط:
1. نگو فقط «غلط».
2. خطای مفهومی را مشخص کن.
3. مسیر درست را نشان بده.
4. کاربر را مجبور به حفظ کردن عدد بدون مفهوم نکن.
5. در صورت وجود عدد، منبع را کنار عدد نمایش بده.

## Numeric exercise rule

هیچ تمرین عددی نباید مقدار منبع را دوباره در چند فایل UI کپی کند. عدد باید از یک data object/versioned source dataset خوانده شود و sourceRef داشته باشد.

## Phase 2 completion rule

Phase 2 وقتی آماده خروج است که برای هر 22 واحد:
- یک Practice تعریف شده باشد؛
- sourceRef مشخص باشد؛
- common mistake مشخص باشد؛
- difficulty مشخص باشد؛
- نوع interaction مشخص باشد؛
- پاسخ و feedback قابل پیاده‌سازی باشد.
