**CRETIQ 6044** یک محیط تعاملی حرفه‌ای برای یادگیری، تمرین و ارزیابی استاندارد ملی ایران ۶۰۴۴:۱۳۹۷ — «بتن آماده، ویژگی‌ها» است.

## محصول

این محصول متن و الزامات استاندارد را به یک تجربه آموزشی قابل مطالعه، مشاهده، تمرین و ارزیابی تبدیل می‌کند؛ با تمرکز بر کاربرد واقعی در زنجیره تولید و کنترل کیفیت بتن آماده.

مسیر یادگیری:

**منبع → فهم → کاربرد → تمرین → تصمیم → ارزیابی**

## قابلیت‌ها

- کتاب وب فارسی و راست‌به‌چپ
- پوشش ۱۵ فصل، ۷ پیوست و کتاب‌نامه
- صحنه‌های تعاملی و انیمیشن مرحله‌ای
- روایت صوتی فارسی و متن همراه
- شبیه‌سازهای منتخب بتن تازه، نمونه‌برداری، مقاومت، تحویل و کنترل تولید
- تمرین‌های سناریومحور و ارزیابی یادگیری
- جست‌وجوی مفاهیم و بندهای مرتبط
- نشانک، ادامه مطالعه و مرکز مطالعه
- نمایش واکنش‌گرا برای دسکتاپ و موبایل
- حالت تمام‌صفحه و پشتیبانی از کاهش حرکت
- اجرای پایه بدون سرویس پولی یا وابستگی اجباری بیرونی
