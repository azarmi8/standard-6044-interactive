# CRETIQ 6044 — Visual System V2

The homepage is intentionally art-directed as an immersive engineering learning experience rather than a dashboard.

Core principles:
- Editorial hierarchy before cards and controls.
- Large typography and full-bleed visual stages.
- Vector-first engineering geometry with restrained motion.
- Material → process → specimen → evidence → decision as the main visual narrative.
- Persian RTL reading remains primary.
- Visualizations are conceptual engineering explainers, not molecular, CFD, or DEM simulations.
- Chapter reader surfaces share the same dark technical visual language.
- Audio narration is generated offline at build time and shipped as static assets.

This document records the visual direction for review and QA.
