# راهنمای کاربر — CRETIQ 6044

## شروع سریع

CRETIQ 6044 یک کتاب آموزشی تعاملی برای استاندارد ملی ایران ۶۰۴۴:۱۳۹۷ «بتن آماده — ویژگی‌ها» است. ساختار آن از ۱۵ فصل رسمی، پیوست‌های الف تا ز و یک سطح کتاب‌نامه تشکیل شده است.

برای اجرای محلی:

```bash
python3 -m http.server 8765 -d site
```

سپس:

```
http://localhost:8765/6044-1397/
```

## روش استفاده

هر واحد آموزشی با یک صحنه مهندسی شروع می‌شود. کنترل‌های Play، Pause، Previous، Next، Step و Progress برای حرکت در مراحل آموزش استفاده می‌شوند. در واحدهای دارای شبیه‌ساز، ورودی را وارد کنید، نتیجه را اجرا کنید و بخش مبنای منبع را بخوانید.

### چهار لایه محتوا

**SOURCE** — خلاصه وفادار به الزام یا داده منبع و دارای ارجاع.

**EXPLANATION** — توضیح آموزشی ساده‌تر برای فهم مفهوم.

**FACTORY APPLICATION** — تبدیل مفهوم به موقعیت واقعی تولید، تحویل یا کنترل کیفیت.

**PRACTICE / SIMULATION** — تمرین، محاسبه یا سناریوی تصمیم‌گیری. داده‌های فرضی آموزشی نباید با الزام استاندارد اشتباه گرفته شوند.

## مسیرهای آموزشی

**Quick Learn** برای مرور سریع، **Full Study** برای مطالعه مرحله‌ای، **Practice** برای حل تمرین و **Exam** برای ارزیابی نهایی مناسب هستند.

برای موضوعات عملی، از بخش‌های شبیه‌سازی مانند نمونه‌برداری، بتن تازه، دمای تحویل، آزمون بتن سخت‌شده، کنترل تولید، ردیابی سفارش تا تحویل و ارزیابی انطباق استفاده کنید.

## جست‌وجو و بازگشت

جست‌وجوی محلی روی مفاهیم و بندهای آموزشی کار می‌کند و به واحدهای مرتبط پیوند می‌دهد. پیشرفت، موقعیت آخر و نشانک‌ها به‌صورت محلی در مرورگر نگهداری می‌شوند؛ برای استفاده پایه به حساب کاربری یا سرویس پولی نیاز نیست.

## Narration

در واحدهایی که فایل صوتی منتشر شده باشد، Narration با Beat آموزشی همگام می‌شود و کنترل Play/Pause/Replay/Speed و Transcript دارد. نسخه فعلی موتور Narration دارای fallback بدون صدا است. تا زمان تأیید انسانی، صدای مصنوعی به‌عنوان صدای نهایی محصول در نظر گرفته نمی‌شود.

## موبایل و دسترسی

محصول برای دسکتاپ و موبایل طراحی شده و حالت reduced-motion دارد. در دستگاه‌های کوچک، کنترل‌ها و محتوای آموزشی باید بدون نیاز به زوم افراطی قابل استفاده باشند.
