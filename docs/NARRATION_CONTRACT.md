# NARRATION CONTRACT — Standard 6044 Interactive

## هدف
روایت فارسی باید هم‌زمان با beat آموزشی حرکت کند و بدون صدا نیز کتاب کاملاً قابل استفاده بماند.

## قرارداد داده
```js
narration: {
  beats: [
    { src: 'audio/fa/ch01-01.mp3', text: 'متن روایت...' },
    { src: null, text: 'متن روایت بدون فایل صوتی...' }
  ]
}
```

## رفتار Engine
- با ورود به beat، transcript همان beat نمایش داده می‌شود.
- اگر `src` وجود داشته باشد، فایل صوتی محلی پخش می‌شود.
- نبودن فایل صوتی نباید اجرای کتاب را متوقف کند.
- Play/Pause و تغییر beat باید روایت را همگام کنند.
- نرخ پخش از داده narration قابل تنظیم است.
- رویدادهای narration برای QA و UI قابل hook هستند.
- فایل صوتی خارجی یا API پولی برای v1 اجباری نیست.

## الزامات محتوا
1. متن روایت از محتوای تأییدشده همان واحد ساخته می‌شود.
2. روایت نباید الزام جدیدی به استاندارد اضافه کند.
3. اعداد، حدود و فرمول‌ها باید با source ledger سازگار باشند.
4. Transcript باید برای کاربر بدون صدا در دسترس باشد.
5. narration باید قابل replay باشد.

## وضعیت
Phase 5 آغاز شد: shared narration/transcript hooks در Engine v0.5 پیاده‌سازی شده‌اند. تولید و QA فایل‌های صوتی در ادامه Phase 5 انجام می‌شود.
